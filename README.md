# 超星学习通全自动刷课与答题脚本

适用于超星“视频+答题”课程类型，帮你脱离超长水课的烦恼，解放时间。

基于 Playwright 和 智谱 AI (GLM-4V) 视觉大模型，实现全自动 100% 看视频、单题精准 AI 识别作答、自动交卷、自动切换下一节。无视字体加密。

## 功能特点

- 自动 100% 播放视频（防切屏、防挂机检测）
- 自动识别并解答单选题、多选题、判断题（基于视觉大模型，无需抓取网页文字）
- 自动交卷并处理二次确认弹窗
- 自动切换下一章节，实现挂机刷课

## 环境准备

1. 安装 Python 3.8+,
   > [!IMPORTANT]
   > **必须勾选**"Add python.exe to PATH"
2. 打开电脑的 CMD 命令行，依次输入以下两条命令并回车，安装所需依赖：
   pip install playwright requests
   playwright install
3. 电脑需安装 Microsoft Edge 浏览器。

## 使用方法

1. 去智谱 AI 开放平台 (https://open.bigmodel.cn/) 注册并获取免费的 API_KEY。
2. 用记事本打开 auto_answer.py 文件，找到配置区，填入你的 API_KEY 和课程页面的网址。
3. 双击同目录下的 start.bat 文件启动程序。
4. 在弹出的 Edge 浏览器中，于 30秒内 登录学习通并点进未学习的课程，停在视频界面。
5. 放下鼠标键盘，去干点别的。
6. 停止方式：在黑框终端按 Ctrl + C（选 Y 确认），或直接关掉黑框。

## 运行产物说明

脚本运行后，会在当前代码所在的同级目录下生成：

- my_edge_profile 文件夹：浏览器登录缓存文件夹（保留此文件夹，下次运行可免登录）。
- temp_screenshots 文件夹：临时截图文件夹（可随时清理）。
- __pycache__ 文件夹：Python 运行缓存（可忽略）。
